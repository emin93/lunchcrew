# LunchCrew Landing (inside main repo)

This folder contains the static landing page for LunchCrew.

## Deploy (Vercel recommended)
- Framework preset: **Other**
- Root directory: `web/landing`
- Build command: *(none)*
- Output directory: `.`

## Local preview
```bash
cd web/landing
python3 -m http.server 8080
```

Then open http://localhost:8080
